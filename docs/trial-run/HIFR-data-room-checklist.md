# Data Room Checklist — Home Is the Foundation Restoration

*What we need from the client before drafting can finalize. Every factual claim in every application traces to one of these documents or a written, attested intake answer — anything we cannot trace gets removed from drafts, not smoothed over.*

## Organizational identity
- [ ] Legal name exactly as registered, and any DBA
- [ ] **EIN** and the IRS EIN assignment letter (CP 575)
- [ ] Kentucky incorporation/organizing documents (articles, bylaws, or church charter)
- [ ] Physical and mailing address; primary contact (name, role, email, phone)
- [ ] Board/leadership list with roles (and whether homeowner-beneficiaries hold governance seats — this gates the SDOP application)
- [ ] Bank account in the organization's name (several funders pay only to an org account)

## Financial
- [ ] Simple operating budget for the current year (even a one-page startup budget)
- [ ] Financial statements if any exist — or a signed statement that none exist yet (acceptable for a startup; funders ask either way)
- [ ] Any donations/in-kind received to date with estimated dollar-equivalent values (the plan's "material value equivalent" tracking — start it now)

## Program documentation (the case log — start immediately)
- [ ] Per-homeowner case file: photos of condition, repair scope, homeowner age band and income band, consent to share
- [ ] Volunteer roster and hours log (volunteer labor may count as match on some programs)
- [ ] Materials inventory from deconstruction/rescue with estimated values
- [ ] Any letters of support (churches, county officials, Gateway/Frontier contacts as relationships form)

## Registrations to start now (long lead times)
- [ ] SAM.gov entity registration + UEI (free; allow 2–6 weeks; required before any federal org-facing application)
- [ ] Deed.org verification for Walmart Spark Good (EIN + organizing documents)

## Decisions the client owns (not paperwork)
- [ ] Fiscal sponsorship: pursue with Frontier Housing (unlocks the foundation tier now) — yes/no
- [ ] File the planned 501(c)(3) CDC's Form 1023-EZ ($275) early — yes/no
- [ ] Governance change to beneficiary-majority for SDOP eligibility — yes/no

*Attestation: before any application is finalized, the organization's authorized representative signs a short statement that the data-room contents are accurate. Drafts carry [CLIENT TO PROVIDE] markers wherever an item above is still missing.*
